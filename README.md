# Network Packet Analyzer

## Description
A Python network sniffing application developed using `scapy` to capture real-time IP packets, inspect transport layer protocols (TCP/UDP/ICMP), and output header metadata and payload data.

## Requirements
- Python 3.x
- `scapy` library
- Npcap (Windows network capture driver)

## Usage
Run with administrative privileges:
```powershell
py packet_analyzer.py
